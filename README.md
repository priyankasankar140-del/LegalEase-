# LegalEase

AI-powered legal document drafting application.

## Features

- AI legal-document drafting
- Gemini integration
- FastAPI backend
- Streamlit frontend
- Editable document preview
- TXT export
- DOCX export
- PDF export
- Branding
- API validation
- Automated tests
- Docker support

## Architecture

Frontend:

Streamlit

Backend:

FastAPI

AI:

Google Gemini

Document generation:

python-docx

PDF:

fpdf2
